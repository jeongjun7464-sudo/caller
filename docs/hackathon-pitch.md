# Magic Caller AI — Wanted AI Championship 2026

## 한 문장

**AI가 마술을 대신하는 것이 아니라, 마술사의 연출과 관객 경험을 강화합니다.**

## 3분 발표

| 시간 | 내용 |
|---|---|
| 0:00–0:20 | 디지털 마술 도구는 설정이 복잡하고 관객 참여가 제한적이라는 문제 소개 |
| 0:20–0:40 | 관객이 스페이드 7을 선택 |
| 0:40–1:00 | 마술사가 터치 패턴으로 화면을 보지 않고 비밀 입력 |
| 1:00–1:30 | `MAGIC PERFORMANCE`가 표시된 앱 내부 모의 전화 수신 |
| 1:30–2:10 | AI 마술사가 색상→무늬→값→카드 순으로 단계별 공개 |
| 2:10–2:35 | 온디바이스 fallback, 상태 머신, FastAPI WebSocket 구조 설명 |
| 2:35–3:00 | 마술사의 기술과 AI 실시간 연출의 결합, 공연·교육 시장 확장성 |

## 라이브 데모 체크리스트

1. 방해 금지, 배터리, 음량을 확인한다.
2. 홈에서 Demo Mode 1을 실행한다.
3. 5초 후 모의 수신 화면에서 `공연용 모의 전화` 표시를 보여준다.
4. 수신 후 단계별 AI 대사를 진행하고 스페이드 7을 공개한다.
5. 관객 이모지 반응을 기록한다.
6. 네트워크를 끄고도 같은 데모가 작동함을 보여준다.

## 기술 구조

- Android: Kotlin, Compose, MVVM, StateFlow, DataStore, WorkManager, TTS
- 안전성: 실제 Telecom API나 시스템 전화 UI 복제 없이 앱 내부에서만 연출
- AI: `DialogueGenerator` 추상화, JSON 검증 가능한 단계형 모델, 로컬 템플릿 fallback
- 백엔드: FastAPI, 추측하기 어려운 세션 코드, WebSocket, 만료와 명령 멱등성
- 개인정보: 관객 계정이나 이름이 필요 없고 음성 원본을 저장하지 않음

## 시장과 확장성

마술사 공연 도구에서 시작해 행사 진행, 체험형 교육, 라이브 스트리밍 참여 장치로 확장할 수 있습니다. 다음 단계는 Room 기반 공연 분석, 웨어러블 리모컨, 다기기 동기화, 관객 반응 기반 대사 추천입니다.
